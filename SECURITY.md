# Security

Anne's Chess Kit runs a local web server that listens on `127.0.0.1` only and stores all data in its `userdata` folder
(see "Your data and privacy" in the README).

If you find a security problem, for example a way for a website or another machine to reach or control the
local server, please report it privately through
[GitHub's private vulnerability reporting](../../security/advisories/new) instead of opening a public issue.
Include the version, your operating system and the steps to reproduce it.
